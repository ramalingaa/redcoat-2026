SVG Streaming Architecture
Claude/Gemini streams SVG tokens → Next.js API route forwards as SSE → React component accumulates tokens into bufferRef → requestAnimationFrame loop injects partial SVG into DOM via innerHTML every ~16ms → browser SVG parser renders partial SVG in real-time → "drawing itself" effect.

Key insight: Browser tolerates incomplete SVG. Renders whatever valid elements exist, ignores broken tags at tail.
SVG Element Painting Order (Critical)
Layer 1 — paper background (#fdfcf8)
Layer 2 — sky / distant exterior / atmosphere
Layer 3 — background structures (buildings, walls)

Human Figure Rule
All human figures use anatomically proportioned bezier paths (Q and C curves). Head = oval path. Arms/legs = two-sided paths showing volume. Clothing = separate path layered over body. Hair = filled path. Face = brows, almond eyes, nose, mouth. Proportions: head = 1/7 to 1/8 total height.
